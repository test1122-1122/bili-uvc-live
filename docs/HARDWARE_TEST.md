# 真机冒烟测试清单

> 本项目开发环境无 Android 设备/模拟器，以下项目需要在真机上逐项验证并记录结果。

## 0. 环境

- [ ] Android 8.0+ 手机，支持 OTG
- [ ] UVC 免驱摄像头（MJPEG，常见 720p/1080p）
- [ ] OTG 转接线；1080p 摄像头建议带供电 USB Hub
- [ ] 已开通直播间的 B 站账号（完成实名认证）
- [ ] 安装 `app-debug.apk`（arm64-v8a）

## 1. UVC 预览

- [ ] 插入摄像头 → 系统弹出 USB 权限 → 允许
- [ ] App 出现预览画面，颜色正确（无绿屏/花屏/上下颠倒）
- [ ] `logcat -s UvcController H264Encoder AacEncoder`：确认 `UVCCamera` open 成功、帧回调持续
- [ ] 拔插摄像头：预览自动恢复/提示断开；直播中拔插应自动停播
- [ ] 多个摄像头时默认选择第一个；切换设备后预览正常

## 2. 编码

- [ ] 720p30 编码正常，`dumpsys media.codec` 能看到 `video/avc` 编码器
- [ ] 1080p30 编码正常（若设备/摄像头支持）
- [ ] 画面无严重延迟（< 1s）
- [ ] 音画同步（口型/动作偏差 < 200ms）；如不同步，检查时间戳（见 `RtmpPublisher`）
- [ ] 关闭音频后仍可推流（B 站后台能看到画面）

## 3. B 站登录与开播

- [ ] 扫码登录成功；顶部显示昵称、直播间号、标题、分区
- [ ] 杀掉 App 重开：登录态仍有效（`SessionStore` 持久化）
- [ ] 「退出登录」后再开播提示先登录
- [ ] 开始直播 → 确认弹窗信息正确 → B 站直播中心 5~10s 内显示「直播中」
- [ ] 直播画面/声音正常，观众端可播放
- [ ] 连续直播 10 分钟：无断流、无内存增长异常、码率稳定
- [ ] 停止直播 → B 站直播中心显示「未开播」
- [ ] 强杀 App（后台清理）→ 重新打开后账号/设置正常；若残留直播，检查停播逻辑（可到 B 站手动关闭）

## 4. 人脸验证 / 异常分支

- [ ] 新账号/风控账号开播触发人脸验证 → 弹二维码 → 手机扫码 → 验证完成自动重试开播
- [ ] 验证二维码过期/取消后的状态（不应崩溃）
- [ ] 网络断开：推流 ERROR 回调、弹窗提示、B 站停播被调用
- [ ] B 站接口返回非 0 错误（如未开通直播间）时展示可读错误

## 5. 生命周期

- [ ] 直播中按 Home → 自动停播并提示（当前设计不支持后台推流）
- [ ] 直播中锁屏 → 同上
- [ ] 直播中旋转屏幕（横竖屏）：预览/推流不断（Activity 配置 `sensorLandscape`，一般锁横屏）
- [ ] 返回键：直播中弹「确定停止直播？」

## 6. 兼容性矩阵（建议）

| 设备 | Android | 摄像头 | 结果 |
|---|---|---|---|
| 例：小米/Redmi | 13 | 罗技 C920 | 待测 |
| 例：华为 | 12 | 某 HDMI 采集卡 | 待测 |
| 例：Pixel | 14 | 通用 UVC | 待测 |

把每项的 `logcat` 关键行、B 站直播中心截图、观众端截图存档到 `docs/test-results/`。

## 7. 已知风险点（优先验证）

1. `H264Encoder` 使用 `COLOR_FormatYUV420SemiPlanar` 输入；部分设备编码器只接受 Surface/Flexible → 可能初始化失败或颜色异常。
2. UVC 只支持 MJPEG 模式；YUYV-only 摄像头可能无画面。
3. 1080p 高码率下手机发热/降频，可能丢帧。
4. B 站 60043 风控分支依赖官方 SDK，App 仅提示手动验证，可能无法自动完成。
5. 登录 Cookie 未加密存储；共用设备建议直播结束后退出登录。
